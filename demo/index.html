The in-memory demo

A live backlog running on a data source that holds one document in a variable. No tracker, no credentials, no backend. Edits are client-side and saved nowhere; reload to get the seed back.

An armed outcome fires once and disarms itself, so the retry it offers can actually land.

The order below is derived by this page, not by the package: the store takes the deriver as a port with no default, because the selection order is its own concern. Every colour and dimension on this page is a CSS custom property — no rule carries a length literal, and a test enforces it — and no edge relies on hue alone.
