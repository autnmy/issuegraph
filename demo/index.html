The in-memory demo

A live backlog running on a data source that holds one document in a variable. No tracker, no credentials, no backend. Edits are client-side and saved nowhere; reload to get the seed back.

An armed outcome fires once and disarms itself, so the retry it offers can actually land.

The order below is @issuegraph/derive’s, not this page’s: the store takes the deriver as a port with no default, and this page fills it with the published derivation rather than a second reading of the ordering rules. What is still the host’s is what the specification puts there — the executor holds (§6.8) and the concurrency cap (§6.5). Every colour and dimension on this page is a CSS custom property — no rule carries a length literal, and a test enforces it — and no edge relies on hue alone.
